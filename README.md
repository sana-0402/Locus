# Locus
Locus is a web app that helps you find the right database for your biotechnology research and further explore available databases. 
Newest version - Locus 2.1
Locus 2.1 : Now with better search confidence score, and added concept-bridging as an technique to domain map. An honest weak-match note is also implemented urging the users to expand their query for better results.
Earlier versions - Locus, Locus 2.0.
